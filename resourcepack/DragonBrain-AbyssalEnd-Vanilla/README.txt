DragonBrain: Abyssal End — Vanilla Texture Pack  (OPTIONAL)
============================================================
For Minecraft Java Edition 1.21.11 (resource pack format 75).

What it does
------------
Refreshes vanilla End textures (End Stone, End Stone Bricks, Purpur,
Obsidian, Crying Obsidian, Dragon Egg, Chorus Plant/Flower, Bedrock,
Ender Pearl, Eye of Ender, Chorus Fruit, Popped Chorus Fruit) with
original artwork in the same palette as the DragonBrain mod's own
blocks, so modded and vanilla End content look like one world.

Every texture in this pack is original work created for DragonBrain
(see tools/generate_assets.py in the DragonBrain repository, function
make_resourcepack). No third-party pack assets are included.

Installation
------------
1. Zip this folder (or use DragonBrain-AbyssalEnd-Vanilla.zip from the
   DragonBrain build/libs, or run ./gradlew zipVanillaResourcePack).
2. Put the .zip in <minecraft>/resourcepacks/.
3. In game: Options -> Resource Packs -> move "DragonBrain: Abyssal End"
   to the right column. Load it ABOVE any other End packs you use if
   you want these textures to win.

The DragonBrain mod itself does NOT require this pack. All mod blocks,
items, creatures and the dragon have their own textures inside the mod.

Compatibility notes
-------------------
- Beyonder - End Tweaks (MIT licence) and Fancy End (CC-BY-NC-ND-4.0)
  are independent packs by other authors. If you use them, download
  them from their Modrinth pages and follow their licences. Load order
  decides which pack's version of a vanilla texture you see.
- No OptiFine/Continuity/CIT/CEM features are used; vanilla rendering
  only.
